
# Contributing

1. Assign an issue and work on a focused feature branch.
2. Do not edit another person's owned folder without coordination.
3. Do not change files under `shared/` without notifying all four owners.
4. Add tests for behavior changes.
5. Do not commit datasets, model binaries, credentials, or personal health information.
6. Open a pull request with purpose, testing performed, and screenshots where useful.
7. Never present demo/mock outputs as real model predictions.
