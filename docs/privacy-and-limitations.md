
# Privacy, safety, and limitations

- This is a research/educational prototype, not a clinically validated diagnostic tool.
- Do not enter real identifiable patient data into demos or public deployments.
- Use synthetic or properly de-identified test fixtures.
- Do not log raw health-related input values by default.
- Document data retention, access, deletion, and security before any real-data use.
- A small dataset does not establish generalization to new hospitals or populations.
- Model explanations show model associations/contributions, not causal medical evidence.
- A tabular target does not provide patient-specific lesion geometry.
- Before any clinical use, independent clinical validation, privacy/security review, and jurisdiction-specific regulatory assessment would be required.
